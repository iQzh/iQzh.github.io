GitHub 自动同步

配置后，你的打卡进度和笔记会自动保存到 GitHub 仓库，换设备打开网页自动恢复。
怎么获取 Token？
1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 点 "Generate new token (classic)"
3. 勾选 repo 权限，生成后复制粘贴到上面
Token 只存在你浏览器本地，不会上传到任何第三方。
